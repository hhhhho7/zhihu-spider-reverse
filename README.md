# 知乎 Web 端加密参数逆向与数据采集 (Webpack 扣代码+补环境)

## 📖 项目简介
本项目针对知乎 Web 端核心接口的加密参数（如 `x-zse-96`）进行了逆向分析。由于目标网站采用 Webpack 模块化打包与高度混淆代码，本项目未采用死磕纯算的方案，而是采用扣取部分代码**Node.js 补环境**的工程化方案，结合 Python 实现跨语言调用，最终成功绕过风控，实现热榜/搜索数据的稳定采集。

## 🛠️ 技术栈
*   **语言**： Python 3.10，JavaScript（Node.js）
*   **逆向工具**: Chrome DevTools (断点跟栈分析)
*   **补环境库**: `jsdom` (伪造 window、navigator 等浏览器指纹)
*   **跨语言通信**:P ython `子过程` 模块
*   **数据处理**: `请求`, `csv`

## 🚀 核心实现思路
1.  **定位入口**: 通过 XHR 断点，顺着调用栈找到生成 `x-zse-96` 的 Webpack 模块。
2.  **代码剥离**: 将核心加密 JS 模块全扣，提取为独立的 `core_logic.js`。
3.  **环境补齐**: 在 Node.js 中，利用 `jsdom` 搭建浏览器底层环境，解决环境检测报错，暴露 `getSignature（）` 方法。
4.  **工程集成**: Python 提取参数，通过 `子过程` 唤醒 Node.js 生成动态签名，最后组装请求头发起请求。
5.  **数据清洗**: 提取 JSON 中的嵌套字段（标题、摘要、热度），容错处理后保存为 CSV。

## 📦 运行指南
1. 安装 Python 依赖: `pip install -r requirements.txt`
2. 安装 Node.js 依赖: `NPM 安装 JSDOM`
3. 运行主程序: `python main.py`
